# Yegara Website Build

Build a polished production-quality marketing website for Yegara Space, a premium coworking space in Addis Ababa, Ethiopia. This should be a real implementation, not a design explanation. Use the attached Instagram screenshot as the primary brand reference and reproduce its visual language: deep navy/near-black, warm white, vivid orange accents, circular sun/radial motif, lowercase yegara wordmark treatment, editorial oversized typography, orange emphasized words, premium architectural/interior photography, and subtle geometric line graphics. Do not turn it into a generic SaaS/coworking template.

Brand/content:
Yegara Space. Positioning: Addis Ababa's premium coworking space for professionals, entrepreneurs, and growing teams. Core message: "One Space, Many Possibilities." Location: Bloom Tower, 3rd Floor, Kazanchis, Addis Ababa. Workspace types: Private Offices, Dedicated Desks, Hot Desks, Meeting Rooms. Also has an in-house café and community/events angle. Instagram: @yegaraspace.et

Homepage:
- Minimal sticky nav with Yegara logo, Spaces, Amenities, Community, About, and orange Book a visit CTA.
- Strong editorial hero with cinematic workspace imagery and headline "One space. Many possibilities."
- Large typographic brand statement with subtle geometric line art.
- Image-led "Find your space" cards for Private Offices, Dedicated Desks, Hot Desks, Meeting Rooms.
- Photo-led "Work. Connect. Create." section with asymmetric composition.
- Refined amenities section without invented numerical claims.
- Community/events section.
- Café/lifestyle section.
- Location/visit CTA for Bloom Tower, Kazanchis.
- Branded footer.

Interaction:
Subtle scroll reveal, image hover/scale, smooth transitions. Fully responsive. Strong accessibility and keyboard focus states. High-end hospitality/workspace feel. Avoid gradients, glassmorphism, generic purple/blue SaaS styling, excessive rounded cards, and template-like UI. Use local/placeholder image assets where needed but make them easy to replace with the original Yegara photography later. Build clean reusable React components and a coherent design token system.
